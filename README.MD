___
## Установка
### Настройка окружения
В корне проекта есть ``.env.example``, требуется настроить подключение к БД PostgreSQL  
И настроить данные по клиенту и серверу (хост и порты)
### Установка БД через docker-compose (опционально)
Если СУБД установлена на локальнй машине, то шаг можно пропустить

В консоли перейти в корневую директорию проекта и ввести команду:
```bash
docker-compose up -d
 ```
После пойдет установка образов и создание контейнеров, сети и томов. Если в консоли контейнеры показали статус `created`, то БД и PgAdmin установлены
### Добавление значений в БД
Для добавления тестовых значений нужно запустить cmd (**Windows**) или sh (**linux**) скрипт, если есть СУБД на базе docker-контейнера, то установка не нужна  
Для запуска скрипта на Linux, в корне проекта ввести команду:
```bash
sh setup_db.sh
```
Для запуска скрипта на Windows достаточно нажать на файл `setup_db.cmd`
### Предзапуск
В папках `backend` и `frontend` ввести команду:
```bash
npm install
```
После дождаться инициализации пакетов
## Запуск
### Автоматический старт через скрипт
В корне проекта ввести команду:
```bash
npm run start
```
### Старт вручную
Запустить 2 консоли и перейти в корень проекта, на первой консоли написать:
```bash
cd backend && npm run start
```
На второй консоли:
```bash
cd frontend && npm run start
```
